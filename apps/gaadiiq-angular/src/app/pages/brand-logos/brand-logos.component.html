How to add / replace a logo

  1. Find the asset file name in the Asset File column above (e.g. assets/brand-logos/tata.svg).
  2. Save your PNG or SVG with that exact filename into apps/gaadiiq-angular/src/assets/brand-logos/.
  3. Run ng serve — the new logo appears everywhere in the app automatically.
  4. To add a new brand: add a row to src/app/data/brands.ts and drop the logo file.
