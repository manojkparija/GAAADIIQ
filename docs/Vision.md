# GAADIIQ.COM — Vision Document

**Version:** 1.0  
**Date:** 2026-06-24  
**Status:** Approved for Phase 0

---

## 1. Vision Statement

GAADIIQ.COM will be India's most intelligent automotive intelligence platform — a destination where every car buyer finds the right vehicle through AI-powered personalisation, predictive analytics, and Generative AI guidance, not just a static comparison grid.

## 2. Mission

Democratise automotive decision-making for Indian buyers by combining comprehensive car data with real-time AI insights, transparent ownership cost modelling, and trusted dealer connections — all at zero cost to the consumer.

## 3. Problem Statement

Indian car buyers face:
- **Information overload** — 300+ models across 25+ brands with thousands of variant permutations.
- **Hidden costs** — Showroom price is only ~60% of 5-year ownership cost (insurance, fuel, maintenance, depreciation).
- **Generic recommendations** — Existing platforms (CarDekho, CarWale, V3Cars) show the same cars to everyone regardless of lifestyle, usage, or budget.
- **Trust deficit** — Reviews are generic; dealer info is opaque; loan/insurance rates are not personalised.
- **No AI layer** — No Indian automotive portal uses LLMs, ML recommendations, or predictive pricing intelligence.

## 4. Solution

GAADIIQ.COM bridges this gap with:

| Capability | Description |
|---|---|
| AI Smart Advisor | Conversational AI (Llama 3 / DeepSeek via Ollama) that asks the right questions and recommends the right car |
| ML Recommendation Engine | Collaborative + content-based filtering trained on Indian buyer profiles |
| Predictive Ownership Cost | 5-year TCO model incorporating fuel prices, depreciation curves, insurance actuarial data |
| Hyper-personalised Search | Filter by 25+ parameters including NCAP rating, boot space, ground clearance |
| Dealer Intelligence | Verified dealer leads with conversion analytics for OEM partners |
| Real-time Market Intel | Price trends, waitlist intelligence, launch alerts |

## 5. Target Market

**Primary:** India — 4.5 million passenger vehicle sales per year (CY2025), growing at 8% CAGR.

**Addressable digital audience:** 45 million active online car researchers per year (per ICRA / SIAM estimates).

## 6. Differentiation vs. V3Cars / CarDekho / CarWale

| Feature | Competitors | GAADIIQ.COM |
|---|---|---|
| AI Advisor | None | Conversational LLM |
| Personalised Recommendations | Basic filters | ML engine + user profile |
| 5-year TCO | Basic calculators | Predictive model |
| NCAP / Safety filter | Limited | Full BHARAT NCAP + Global NCAP |
| Dealer lead quality | Volume-based | Intent-scored leads |
| EV intelligence | Minimal | Full charging infrastructure overlay |
| Subscription tier | None | Premium analytics + alerts |

## 8. Guiding Principles

1. **AI-first** — Every feature is enhanced by intelligence, not bolted on.
2. **India-first** — Indian roads, fuel prices, cities, and buyer behaviour drive every algorithm.
3. **Transparency** — Total cost of ownership, not just on-road price.
4. **Zero cost to buyer** — Always free; monetise through B2B (dealers, OEMs, affiliates).
5. **Privacy by design** — No PII sold; data used only to improve recommendations.
6. **Mobile-first** — 78% of Indian users on mobile; performance budget enforced.
