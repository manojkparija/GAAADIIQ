Business Requirements Document (BRD)
Feature: AI-Powered Car Image Upload & Intelligent Asset Management
Project: GAADIIQ – AI-Powered Automotive Intelligence Platform
Module: Admin Portal – Car Image Management
Version: 1.0
________________________________________
1. Business Objective
To provide a centralized AI-powered image management system where the Admin uploads a vehicle image only once, and the system automatically categorizes, stores, tags, and displays the image across all applicable sections of the GAADIIQ platform, including Manufacturer, Model, Variant, Search, AI Advisor, Comparison, and Dealer Portal.
________________________________________
2. Business Problem
Current image management systems often require duplicate uploads for different pages (Manufacturer, Model, Variant), resulting in:
•	Duplicate storage 
•	Increased maintenance effort 
•	Inconsistent image updates 
•	Poor scalability 
•	Difficult search and retrieval 
GAADIIQ requires a single-source image repository that intelligently organizes and displays images based on metadata.
________________________________________
3. Business Requirements
BR-001: Image Upload
The Admin shall be able to upload one or multiple vehicle images from the Admin Portal.
Supported File Types
•	JPG 
•	JPEG 
•	PNG 
•	WEBP 
•	HEIC 
•	TIFF 
Maximum upload size shall be configurable (up to 15 GB per file as per project requirement).
________________________________________
BR-002: Mandatory Image Details
During image upload, the Admin shall provide the following information:
Field	Mandatory	Description
Manufacturer	Yes	Tata, Mahindra, Hyundai, etc.
Model	Yes	Nexon, Punch, Safari
Variant	Optional	Fearless+, Smart+, Pure, etc.
Model Year	Yes	2025, 2026
Body Type	Yes	SUV, Sedan, Hatchback
Fuel Type	Yes	Petrol, Diesel, EV, Hybrid, CNG
Transmission	Yes	Manual, Automatic, AMT, DCT
Image Category	Yes	Front, Rear, Side, Interior, Dashboard, Engine, Boot, Safety, Gallery, 360°
Color	Optional	Red, White, Blue, Grey, etc.
Primary Image	Optional	Yes/No

BR-004: AI Metadata Extraction
If the uploaded file name or embedded metadata contains useful information, the AI engine shall automatically identify:
•	Manufacturer 
•	Model 
•	Variant 
•	Year 
•	Image View 
•	Category 
•	Color 
Example:
Uploaded File
Tata_Nexon_FearlessPlus_Front_2025.webp
AI extracts
Manufacturer = Tata
Model = Nexon
Variant = Fearless Plus
Year = 2025
Category = Exterior Front
The Admin may edit the extracted information before saving.

AC-010	Image metadata supports SEO, AI search, and future analytics capabilities.
Recommendation for GAADIIQ
To support a large-scale automotive platform, this module should be implemented as an Enterprise Digital Asset Management (DAM) service rather than a simple file upload feature. Treat images as reusable assets with rich metadata and AI enrichment. This design will allow the same image to power the Manufacturer page, Model page, Variant page, AI Advisor, Comparison Engine, Dealer Portal, and future mobile applications without duplication, making the platform easier to maintain and scale.
